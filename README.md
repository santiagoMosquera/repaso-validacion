# Movilis Práctica

Plataforma de práctica académica construida con Next.js y preparada para Vercel.

## Ejecución local

```bash
npm install
npm run dev
```

## Publicación en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel selecciona **Add New → Project**.
3. Importa el repositorio y conserva el preset **Next.js**.
4. Presiona **Deploy**. No requiere base de datos ni variables de entorno.

## Bancos de preguntas

- Catálogo: `public/data/banks.json`
- Matemática 1: `public/data/0101-matematica-1.json`

Cada banco nuevo debe agregarse como archivo JSON dentro de `public/data/` y registrarse en `banks.json`.
